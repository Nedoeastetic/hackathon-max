# 🏠 Аварийный диспетчер МКД

## Краткое описание

**Аварийный диспетчер МКД** — это интеллектуальная система для автоматизации обработки обращений жителей многоквартирных домов через мессенджер MAX. Система использует AI для классификации проблем (протечки, поломки, уборка и т.д.) и автоматической маршрутизации заявок к подходящим мастерам.

## 🎯 Проблема

Жители МКД сталкиваются с трудностями при сообщении о проблемах:
- Не знают, к какой категории относится проблема
- Не понимают, кому адресовано обращение
- Тратят время на ручное описание и уточнения
- Не отслеживают статус выполнения заявки

## 💡 Решение

Система автоматически:
1. **Принимает** обращение через MAX (текст + фото)
2. **Анализирует** с помощью AI (компьютерное зрение + NLP)
3. **Классифицирует** проблему (8 категорий, 24 подкатегории)
4. **Маршрутизирует** заявку к подходящему мастеру
5. **Отслеживает** статус выполнения

## 🔧 Технологии

- **Backend:** Node.js + Express
- **Database:** SQLite (легковесная, для 2GB RAM сервера)
- **Frontend:** HTML/CSS/JavaScript (Vanilla)
- **AI:** Внешний API (CV v4 + Text v3)
- **Containerization:** Docker + Docker Compose
- **Reverse Proxy:** Nginx

## 🚀 Быстрый запуск

```bash
# 1. Распаковать архив
tar -xzf max-hackathon-docker.tar.gz
cd docker-deploy

# 2. Создать .env файл
cp .env.example .env
# Добавить MAX_BOT_TOKEN в .env

# 3. Запустить
docker-compose up -d --build

# 4. Проверить
docker-compose ps  # Должны быть 2 healthy контейнера
```
