# Разделение ролей: Житель и Мастер

## Что изменилось

Теперь интерфейс чётко разделён на две роли:

### 👤 Житель
- **Чат с ботом** — отправка обращений (текст + фото)
- **История заявок** — просмотр всех своих обращений
- **Статусы** — отслеживание выполнения заявок

### 🔧 Мастер
- **Дашборд заявок** — просмотр доступных и своих заявок
- **Фильтры** — доступные / мои / все
- **Действия** — взять заявку, начать работу, выполнить

## Как использовать

### 1. Запустите приложение
```bash
npm run dev
```

### 2. Выберите роль
При запуске появится экран с двумя кнопками:
- **Житель** — для отправки обращений
- **Мастер** — для выполнения заявок

### 3. Житель отправляет заявку
1. Нажмите "Житель"
2. В чате отправьте текст или фото
3. Ответьте на уточняющие вопросы
4. Подтвердите заявку
5. Перейдите на вкладку "Заявки" чтобы увидеть статус

### 4. Мастер берёт заявку
1. Вернитесь к выбору роли (кнопка ←)
2. Нажмите "Мастер"
3. Увидите доступные заявки
4. Нажмите "Взять заявку"
5. Нажмите "Начать работу"
6. Нажмите "Выполнено"

### 5. Житель видит результат
1. Вернитесь к роли "Житель"
2. Перейдите на вкладку "Заявки"
3. Увидите статус "Выполнена" и имя мастера

## Фильтры мастера

- **Доступные** — заявки без исполнителя (только что созданные)
- **Мои** — заявки, которые мастер взял в работу
- **Все** — все заявки в системе

## Статусы заявок

```
Ожидает → Назначена → В работе → Выполнена
```

- **Ожидает** — заявка создана, ждёт мастера
- **Назначена** — мастер взял заявку
- **В работе** — мастер начал работу
- **Выполнена** — проблема решена

## Демонстрация на хакатоне

### Полный сценарий (5 минут):

1. **Показать выбор роли** (30 сек)
   - Запустить приложение
   - Показать экран выбора

2. **Житель отправляет заявку** (1 мин)
   - Выбрать "Житель"
   - Отправить "Не работает свет на лестнице"
   - Подтвердить заявку

3. **Показать историю** (30 сек)
   - Перейти на вкладку "Заявки"
   - Показать статус "Ожидает"

4. **Мастер берёт заявку** (1 мин)
   - Вернуться к выбору роли
   - Выбрать "Мастер"
   - Показать доступные заявки
   - Взять заявку

5. **Мастер выполняет работу** (1 мин)
   - Начать работу
   - Завершить работу
   - Показать статус "Выполнена"

6. **Житель видит результат** (30 сек)
   - Вернуться к жителю
   - Показать обновлённый статус

## Преимущества

✅ **Чёткое разделение** — каждый видит только своё  
✅ **Безопасность** — житель не может менять статусы  
✅ **UX** — интерфейс адаптирован под задачу  
✅ **Демонстрация** — легко показать полный workflow
