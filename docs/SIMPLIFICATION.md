## Что осталось

### Локальная симуляция AI
Теперь приложение использует **только локальную симуляцию** для анализа текста и изображений:

- **Анализ текста**: Поиск ключевых слов в тексте (теч, протечк, труб, нет света и т.д.)
- **Анализ изображений**: Симуляция на основе описания (демо-режим)
- **Fusion логика**: Объединение результатов по правилам HIGH/MEDIUM/LOW

### Упрощенный workflow
```
Пользователь вводит текст
    ↓
Локальный анализ (ключевые слова)
    ↓
Определение категории и подкатегории
    ↓
Fusion с фото (если есть)
    ↓
Создание заявки
```

## Преимущества упрощения

✅ **Работает без VPN** - не зависит от внешних сервисов  
✅ **Быстрее** - нет сетевых задержек  
✅ **Надежнее** - нет проблем с доступностью API  
✅ **Проще** - меньше кода, легче поддерживать  
✅ **Демонстрация** - идеально подходит для хакатона  

## Как работает сейчас

### Анализ текста
```typescript
// Пример: "В подвале течёт труба"
1. Поиск ключевых слов: "теч", "труб"
2. Определение категории: WATER_SUPPLY
3. Определение подкатегории: PIPE_LEAK
4. Расчет уверенности: 0.85
```

### Анализ фото (демо-режим)
```typescript
// Пользователь выбирает тип фото
1. "протечка" → WATER_SUPPLY, HIGH severity
2. "грязь" → CLEANING, LOW severity
3. "дерево" → YARD, MEDIUM severity
```

### Fusion логика
```typescript
// Если есть и текст, и фото
1. HIGH: категория текста == категория фото
2. MEDIUM: категория в top3 другого источника
3. LOW: нет пересечений → нужны уточнения
```
