# 🚀 Запуск с анализом реальных фото

## Проблема

Веб-прототип работает в браузере и не может напрямую обращаться к ML API из-за CORS-политики.

## Решение

Создан прокси-сервер (`proxy-server.js`), который:
- Принимает запросы от браузера
- Перенаправляет их на ML API
- Возвращает результаты обратно в браузер

## 📋 Инструкция по запуску

### Шаг 1: Запустите прокси-сервер

В первом терминале:

```bash
node proxy-server.js
```

Вы увидите:
```
🚀 Proxy server running on http://localhost:3001
📡 Forwarding to ML API: http://193.108.113.153:8000
```

### Шаг 2: Запустите веб-прототип

Во втором терминале:

```bash
npm run dev
```

### Шаг 3: Откройте браузер

Перейдите на `http://localhost:5173`

## ✅ Как это работает

1. Пользователь загружает фото в веб-прототипе
2. Браузер отправляет фото на прокси-сервер (`localhost:3001`)
3. Прокси-сервер перенаправляет фото на ML API (`193.108.113.153:8000`)
4. ML API анализирует фото и возвращает результат
5. Прокси-сервер возвращает результат в браузер
6. Веб-прототип показывает результат анализа

## 🎯 Что теперь доступно

### Анализ реальных фото
- Загрузите фото протечки → ML API определит `WATER_SUPPLY`
- Загрузите фото упавшего дерева → ML API определит `YARD`
- Загрузите фото кота → ML API определит `NOT_INCIDENT`

### Анализ текста через ML API
- "Не работает свет" → `ELECTRICITY / NO_LIGHT_STAIRWELL`
- "В подвале течёт труба" → `WATER_SUPPLY / PIPE_LEAK`

### Fusion (текст + фото)
- Текст: "Течёт труба" + Фото протечки → `WATER_SUPPLY` (HIGH confidence)
- Текст: "Упало дерево" + Фото протечки → `NEEDS_CLARIFICATION` (конфликт)

## 🔄 Альтернативный запуск

Можно запустить оба сервера одной командой:

```bash
npm run dev:full
```

Это запустит прокси-сервер и веб-прототип одновременно.

## ⚠️ Если прокси-сервер не запущен

Веб-прототип будет работать в режиме симуляции:
- Текст анализируется локально (ключевые слова)
- Фото не анализируются (показывается сообщение о необходимости прокси)

## 🔧 Проверка работы прокси

```bash
curl http://localhost:3001/api/health
```

Должен вернуть:
```json
{
  "status": "ok",
  "models": {
    "cv": "cv-v4-2026-09-29",
    "text": "text-v3-2026-09-29"
  }
}
```
