# Как отслеживать работу ML API

## Быстрая проверка

### 1. Посмотрите на индикатор в заголовке чата
- 🟢 **Зелёный "ML API"** → API работает ✅
- 🟠 **Оранжевый "Симуляция"** → API недоступен ⚠️

### 2. Нажмите кнопку 🔍
Рядом с переключателем режимов есть кнопка проверки. Нажмите её для ручной проверки ML API.

### 3. Откройте консоль браузера (F12)
Смотрите логи:
```
✅ ML API доступен
✅ Используем ML API через прокси
📝 Text API результат: { ... }
```

## Переключатель режимов

В заголовке чата есть выпадающий список:

| Режим | Когда использовать |
|-------|-------------------|
| **Авто** | По умолчанию. API есть → используем API, нет → симуляция |
| **Только API** | Когда нужно гарантировать использование реального ML API |
| **Симуляция** | Для тестирования без внешних сервисов |

## Если хотите, чтобы работал только API

1. Выберите режим **"Только API"** в переключателе
2. Запустите прокси-сервер:
   ```bash
   node proxy-server.cjs
   ```
3. Если API недоступен — увидите ошибку с инструкцией

## Панель статуса

В начале чата отображается панель:

**✅ ML API подключен**
```
Используем реальный ML API для анализа. Прокси-сервер работает.
```

**⚠️ Локальная симуляция**
```
Прокси-сервер не запущен. Для использования реального ML API выполните:
node proxy-server.cjs
```

## Автоматическая проверка

Приложение проверяет ML API каждые 30 секунд. Если API появится — индикатор обновится автоматически.

## Пример использования

### Запуск с реальным ML API:
```bash
# Терминал 1: прокси-сервер
node proxy-server.cjs

# Терминал 2: приложение
npm run dev
```

Результат: Индикатор показывает "ML API" ✅

### Запуск без прокси:
```bash
# Только приложение
npm run dev
```

Результат: Индикатор показывает "Симуляция" ⚠️

## Устранение проблем

**Проблема:** Индикатор показывает "Симуляция", хотя прокси запущен

**Решение:**
1. Нажмите кнопку 🔍
2. Проверьте консоль браузера (F12)
3. Убедитесь, что прокси работает на порту 3001

**Проблема:** Режим "Только API" показывает ошибку

**Решение:**
1. Запустите прокси: `node proxy-server.cjs`
2. Дождитесь: `🚀 Proxy server running on http://localhost:3001`
3. Нажмите кнопку 🔍
